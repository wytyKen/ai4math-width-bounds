Later formalization does not retroactively change the claims made in earlier PDFs. The full semigroup-to-lex reduction remains outside the end-to-end Lean development. Mathematical novelty and a future paper's author/responsibility record remain unresolved.

For the full current argument and code mapping, use [PROOF_NARRATIVE](../docs/PROOF_NARRATIVE.md) and [STATEMENT_MAP](../docs/STATEMENT_MAP.md). The v0.4 PDF is a fixed delivery report; a future submission manuscript must be prepared separately.

The [reproducibility guide](../docs/REPRODUCIBILITY.md) explains Lean, Python, PDF, and archive checks. Preserve fixed versions and build new PDF experiments in a separate working copy/output rather than overwriting accepted binaries. Do not run a historical build command simply because it appears in an old review note.

The [original Chinese v0.1 review guide](../research/frozen/pre_english_20261007/paper/README.md) and [v0.2 review guide](README_v0_2.md) remain historical context. English is the maintenance language for this index and future primary manuscript documentation.
