## Contracts: complete conditions represented by the abbreviations

Let K be any field, A = K[x,y,z], m = (x,y,z), with variable order x > y > z. Lean's `Ring K` is exactly `MvPolynomial (Fin 3) K`. We write T(i,j,k) for standardness to avoid confusion with the ring A; combinatorial source files generally name this predicate `A`.

**G — combinatorial contract.** A predicate T : ℕ³ → Prop satisfies `LexCounting.StandardLex T`: it is downward closed coordinatewise, and at fixed total degree, reducing the first differing x or y exponent preserves standardness. We are also given w,a ∈ ℕ, w ≥ 4, a ≥ 2, `hInitial : ∀ d, d < a → T d 0 0`, `hx : ¬ T a 0 0`, and

```text
for every d ∈ ℕ:   Σ_(t=0)^d H_t ≤ 1+dw,
where H_t = hilbert3(T,t).
```

No ring, finite colength, Tor object, or terminal column budget is assumed. When a row uses only some G conditions, those weaker conditions are listed explicitly.

**Q — actual-dimension contract.** `{K : Type*} [Field K]`; `S ⊆ (Fin 3 →₀ ℕ)`; `hUp : IsUpperSet S`; `hLex : IsLexExponentSet S`; I = `monomialIdeal S` is nonzero; `hOne : standard I 1 0 0`; w ≥ 4; and, for **every** d ∈ ℕ,

```lean
(∑ t ∈ range (d + 1),
  Module.finrank K (quotientHomogeneous (K := K) S t)) ≤ 1 + d * w
```

Q does not require the whole quotient A/I to be finite-dimensional. The actual section bounds in N2/N3 hold under this weaker contract. Q_t(I) = `quotientHomogeneous S t` is the image of the degree-t homogeneous polynomials in the actual quotient. The number ell = dim_K `xySubspace I` is the dimension of the complete subspace spanned by quotient monomials with z exponent zero.

**C — main-model contract.** Add the explicit finite-colength assumption `[Module.Finite K (A ⧸ I)]` to Q; nonzeroness follows from it and is not an extra assumption. The equivalent packaged structure is [LexExtremal.Admissible](../lean/WidthBounds/LexGrowthTheta.lean#L24). That structure itself does not contain w ≥ 4, which must be supplied when using the main results. Under the traditional monomial interpretation, x ∉ I and lex imply no degree-one relations; this document does not claim a new standalone Lean declaration `I ⊆ m² ↔ x ∉ I`. `Field K` imposes no characteristic-zero, infinite-field, or algebraic-closure restriction. The parameter w is a budget parameter and need not be realized as a difference of semigroup generators.

**D — concrete boundary contract without width.** K is any field, `I : Ideal (Ring K)` is an actual ideal, `hZ : ∃ b, monomial3 0 0 b ∈ I`, `a : ℕ`, `n : ℕ → ℕ`, `hx : monomial3 a 0 0 ∈ I`, `hLex : IsLex I`, `hn : ∀ i j, standard I i j 0 ↔ j < n i`, and `hInitial : ∀ d, d < a → standard I d 0 0`. Constructing the quotient resolution additionally requires `hSpan : Ideal.span (exponentMonomials (boundaryExponents I hZ a n)) = I`. Vanishing of differentials modulo m and the four Tor dimensions additionally require `hI : I ≤ variableIdeal`. D requires no w, budget, a ≥ 2, or separate finite-colength instance. The C endpoints construct the required data instead of asking users to guess them.

“Lean compiled” below refers to the historical acceptance scope just described. “Traditional” means a natural-language proof or an interface to literature already read, not a new Lean declaration. “Candidate” concerns unresolved contribution attribution only: proof status and novelty status are separate axes.
