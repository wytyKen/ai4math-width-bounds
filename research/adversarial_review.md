# 第二轮反方审查记录

日期：2026-09-23。范围：有限余长 lex 理想的候选组合引理、原论文归约接口，以及算术证书的输入域。

结果：本轮未发现实质逻辑漏洞或反例。该结论不等同于人类领域专家审稿，也不确认新颖性。

## 重新检查的断言

| 断言 | 审查理由或证据 |
|---|---|
| `h_d=d+1` 对 `d<alpha` | lex 性使最小纯 x 幂次数等于初始次数，之前不存在理想中的单项式。 |
| `h_(d+1)<=h_d` 对 `d>=alpha-1` | 标准单项式不能为纯 x 幂；除以 y 是到前一次数标准单项式的单射。 |
| 三变量标准单项式至少 `q_d(h_d)` 个 | 逐一按 x 指数计数全部 y,z 尾部，集合不交；lex 初段的补集是后缀，方向正确。 |
| 累计约束推出包络 | 过去各次数高度至少为当前高度，且 q 在允许的高度范围内单调；等差求和中的常数为 `alpha+d+3-h`。 |
| 截断完整 | 所有低于 beta 次的 y,z 单项式均标准，给出 `beta<=2w-2`；证书使用更松的 `2w` 截止，仍覆盖全部项。 |
| 从长度到 Betti 数 | K 的边界有恰好 alpha+1 个不可约生成元；CMS 式(7)适用于末变量截面和有限余长。注意 ideal/module 与 quotient/ring 下标差 1。 |
| 证书范围 | 全部267组满足前缀约束的 `(w,alpha)` 都通过；Lean 的循环端点正确，实际输入域内自然数减法无意外截断。 |

主线程另从指数三元组直接枚举次数0到9的230个同次 lex 切片，核对强制标准单项式集合与计数方向；全部通过。该有限检查是推导的辅助检查，不替代一般证明。

## 文献连接

- CMS 原文第四节明确将帽号定义为模最后一个变量；式(7)需要有限余长，候选引理显式保留此条件。
- 宽度3的四生成元必为连续四整数。Herzog–Stamate，arXiv:1308.4644v3，命题2.7给出 `r=4` 的所有正次数 Betti 数界。来源：<https://arxiv.org/pdf/1308.4644>。
- 任意三变量lex理想的宽度3版本不成立，已有反例必须保留，不能把半群的特殊边界情形混入组合引理。

## 第三轮：完成形式化后的语义审查

本节是新增组合模块统一编译后的独立语义审查，主线程已保存实际构建日志 `results/lean_combinatorial_build.txt`。

- `small_width_binomial_bounds` 没有把待证的前缀计数、单调性、三维下界、参数覆盖、包络或总长度界直接当作假设。这些结论均从 `StandardLex`、首个非标准纯 x 幂的条件和累计三维计数预算导出。
- `sectionLength` 的截断没有遗漏尾部：`Cutoff` 证明所有更高次数消失，`sectionLength_eq_sum_of_ge` 证明任意更长的部分和都与之相等。
- 未发现实质语义漏洞。最终定理是标准单项式集合的组合定理，并未要求三维标准集有限；回到 CMS 式(7)时，必须保留原理想有限余长假设。
- 具体边界例子：`L=(x^2,xy,xz,y^2,yz)` 有无限多个标准 `z` 幂，可以满足组合条件；它不满足式(7)要求的有限余长条件。
- 实际 lex 理想到标准集接口、计数与商环维数和长度的识别、Betti 数公式及数值半群归约，仍属于未整体形式化的代数层。
- 当前主定理公理依赖为 `propext`、`Classical.choice`、`Quot.sound`。不能把原有限算术证书的“无公理依赖”描述套用于新的全部组合证明。
