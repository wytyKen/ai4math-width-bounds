## 1. 精确通过的命题及假设

令 `A : N^3 -> Prop` 是满足以下两条件的标准单项式集合：

- 整除下闭；
- 在同一总次数、变量顺序 `x>y>z` 下 lex 向下闭。

令整数 `w>=4`、`alpha>=2`，且 `A(d,0,0)` 对每个 `d<alpha` 成立而 `A(alpha,0,0)` 不成立。令 `H_d` 为总次数 `d` 的三维标准单项式数，并假设对**全部** `d>=0` 有

`sum_{t=0}^d H_t <= 1+d*w`。

则二维截面长度 `ell = #{(i,j): A(i,j,0)}` 有限，且

`alpha+1+ell <= binom(w+1,2)-1`，

`alpha+2*ell <= 2*binom(w+1,3)`，

`ell <= 3*binom(w+1,4)`。

因此用户提出的有限余长三变量 lex 理想 `L ⊂ m²` 版本成立：理想的补集满足上述闭包，有限余长保证首个纯 `x` 禁止幂存在，`L ⊂ m²` 保证 `alpha>=2`。组合证明实际不需要三维有限余长；但把数值表达式识别为理想 Betti 数时，R006 保留有限余长假设是正确的。

这正对应源码中 `StandardLex.down` 和 `StandardLex.lex` 的条件；没有额外隐含的强稳定性或特征假设。

## 2. 独立重建列有限性与终端预算

若 `A(i,j,0)` 成立，令 `d=i+j`。同次 lex 下闭给出 `A(0,d,0)`。对 `0<=t<=d`，整除下闭与同次 lex 下闭使全部 `t+1` 个 `y,z` 单项式标准。因此

`(d+1)(d+2)/2 <= sum_{t=0}^d H_t <= 1+d*w`。

当 `d>0` 时消去正数 `d` 得 `d+3<=2w`。因而二维支持只可能出现在 `d<=2w-3`（`d=0` 单独显然成立）。此论证对所有 `w>=4` 有效，不需要原小宽度上界 `w<=39`；其内容与 `Cutoff.lean` 中相应已存引理一致。

定义 `n_i = #{j : A(i,j,0)}`。整除下闭使每列恰好是 `0<=j<n_i`。对 `0<=i<alpha`，有 `n_i>=1`；对 `i>=alpha`，整列为空，否则整除下闭会推出 `A(alpha,0,0)`。于是 `ell=sum_{i<alpha} n_i`。

取第 `i` 列顶端 `A(i,n_i-1,0)`。若 `i>0`，向 lex 更小的单项式移动得到 `A(0,i+n_i-1,0)`；`i=0` 时无需移动。因此

`i+n_i<=n_0`。

`A(0,n_0-1,0)` 确实存在，故二维最高总次数**恰好**为 `D=n_0-1`。`n_0>=1`，这里没有对自然数负一的隐性使用。

对固定 `i<alpha`，每个 `(j,k)` 满足 `j+k<n_i` 时，`A(i,j+k,0)` 已标准，把 `y^k` 换为 `z^k` 保持总次数并使 lex 变小，从而 `A(i,j,k)` 标准。这些点的总次数满足

`i+j+k <= i+n_i-1 <= D`。

每列共有 `1+2+...+n_i = n_i(n_i+1)/2` 个这样的点。不同 `i` 对应不同第一坐标，所以没有重复计数。把它们注入全部总次数不超过 `D` 的标准点，直接得到

`sum_{i<alpha} n_i(n_i+1)/2 <= sum_{d=0}^D H_d <= 1+(n_0-1)*w`。

**结论：终端预算正确。** 三维标准集合即使无限，每个截至 `D` 的计数仍有限；注入只给下界，不错误地断言所有三维标准点都来自这些三角形。

## 3. alpha 的前缀约束

当 `d<alpha` 时，纯 `x^d` 标准，且它是同次 lex 最大的单项式。因此所有同次单项式都标准，`H_d=binom(d+2,2)`。取预算次数 `alpha-1`，得

`binom(alpha+2,3) <= 1+(alpha-1)*w`。

独立展开恒等式

`alpha(alpha+1)(alpha+2)-6 = (alpha-1)(alpha²+4alpha+6)`。

因为 `alpha>=2`，可除以正数 `alpha-1`，得到 `alpha²+4alpha+6<=6w`。若 `alpha>=w-1`，由于二次式在非负参数处单调，有

`6w >= (w-1)²+4(w-1)+6 = w²+2w+3`，

从而 `(w-1)(w-3)<=0`，与 `w>=4` 矛盾。整数性给出 `alpha<=w-2`。

**结论：该上界正确。** `alpha>=2`、整数性和 `w>=4` 都在此处有明确用途，不能删除。

## 4. 完成平方、Cauchy 与严格比较

以下在整数或实数中运算，以避免自然数截断减法。令

`v_0=2n_0+1-2w`，`v_i=2n_i+1 (1<=i<alpha)`，

`S=sum v_i=2ell+alpha-2w`，`Q=sum v_i²`。

逐项展开得

`Q = 4 sum n_i(n_i+1)+alpha-8wn_0-4w+4w²`。

终端预算乘以 `8` 后给出 `4 sum n_i(n_i+1)<=8+8wn_0-8w`，故

`Q <= 4w²-12w+8+alpha = 4(w-1)(w-2)+alpha`。

令 `a=alpha`。纯整数恒等式

`a sum v_i²-(sum v_i)² = sum_{i<j}(v_i-v_j)² >= 0`

给出 `S²<=a[4(w-1)(w-2)+a]`。**`v_0` 为负完全允许**，不需要错误的逐项非负假设。

令 `U=(w-2)(w+1)=w²-w-2`，`T=U-a`。`a<=w-2` 蕴含

`T>=w(w-2)>0`。

为独立复核因式分解，先消去 `a²`：

`T²-a[4(w-1)(w-2)+a]`

`=U²-2Ua-4a(w-1)(w-2)`

`=(w-2)[(w-2)(w+1)²-2a(3w-1)]`。

由于 `w-2>0`、`3w-1>0`，代入 `a<=w-2` 的方向正确，得到下界

`(w-2)²[(w+1)²-2(3w-1)] = (w-2)²(w-1)(w-3)>0`。

因此 `S²<T²`。结合 `T>0`，有 `S<T`（也可直接假设 `S>=T>0` 再平方反证）；无需假设 `S` 正。

整理 `2ell+a-2w < w²-w-a-2` 得

`a+1+ell < w(w+1)/2`。

两边均为整数，遂得目标强化界 `a+1+ell<=binom(w+1,2)-1`。从列预算到最终界的整条链均适用于任意整数 `w>=4`，没有宽度或 alpha 的枚举。

## 5. 另外两界与边界反例

令 `C=binom(w+1,2)`。第一界给出 `ell<=C-alpha-2`，于是

`alpha+2ell<=2C-alpha-4<=2C`，`ell<=C`。

`binom(w+1,3)/C=(w-1)/3>=1`，以及

`3binom(w+1,4)/C=(w-1)(w-2)/4>=1`，

都由 `w>=4` 成立，故另外两项目标界正确。比值的分母 `C>0`，无除零问题。

独立明确边界例：

- `w=4`，取 `L=(x²,xy,xz)+(y,z)^5`。列长为 `(5,1)`，`alpha=2`，`ell=6`，Hilbert 函数 `(1,3,3,4,5)`，累计值 `(1,4,7,11,16)` 均满足预算。`alpha+1+ell=9=binom(5,2)-1`，所以强化常数 `-1` 在允许的全部 `w>=4` 范围内不能统一换为 `-2`。
- `w=3`，取 `L=(x²,xy,xz)+(y,z)^3`。列长 `(3,1)`，累计值 `(1,4,7)` 满足预算，但 `alpha+1+ell=7>binom(4,2)=6`。这是真正的有限余长 lex 理想，且包含于 `m²`。它确认一般 lex 命题不能延伸到 `w=3`；不否定另行处理的半群宽度 3 结论。
