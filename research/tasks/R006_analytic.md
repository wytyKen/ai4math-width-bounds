# R006：全部宽度的解析列计数上界

日期：2026-09-23。交接方式：文件。独占文件为本报告、`scripts/research_analytic.py` 与 `results/research_analytic.json`。

**状态：得到一个不依赖有限参数枚举的完整纸面证明。** 在现有 `StandardLex` 组合假设、`alpha >= 2`、整数 `w >= 4` 及全部次数的累计预算下，证明了更强的

\[
\boxed{\alpha+1+\ell\le\binom{w+1}{2}-1.}
\]

另外两个原目标界随即成立。证明适用于全部 `w >= 4`，无需把 `w >= 40` 交给 CMS 的大宽度定理。**这只是组合部分的改进；本报告没有修改 Lean、稿件或文献归约，没有证明新颖性，也没有把新的解析路线形式化。** `mu(L)` 与上述表达式的识别仍以项目已经单独讨论的有限余长及 Betti 公式为前提。

## 1. 假设与列长度

沿用 `research/combinatorial_proof.md` 的记号。`A(i,j,k)` 表示标准单项式，满足整除下闭及同次 lex 向下闭；`x^d` 在 `d < alpha` 时标准，`x^alpha` 不标准；并且

\[
\sum_{t=0}^{d}H_t\le1+dw\qquad(d\ge0).
\tag{1}
\]

先用现有截断引理：二维标准单项式的总次数不超过 `2w-3`。该引理对所有 `w >= 4` 有效，其证明不含 `w <= 39` 条件。于是可对 `0 <= i < alpha` 定义

\[
n_i=\#\{j\ge0:A(i,j,0)\}.
\]

整除下闭说明第 `i` 列恰好是 `0 <= j < n_i`；`x^i` 标准说明 `n_i >= 1`；`x^alpha` 不标准说明更大的 `i` 列为空。因此

\[
\ell=\sum_{i=0}^{\alpha-1}n_i.
\tag{2}
\]

若 `x^i y^(n_i-1)` 标准，则同次 lex 向下闭保证 `y^(i+n_i-1)` 标准。所以

\[
i+n_i\le n_0.
\tag{3}
\]

特别地，二维标准集的最大总次数恰好是 `D=n_0-1`。这里不需要三维标准集有限；现有二维截断已经足够。

## 2. 一次累计预算控制全部列的平方和

对固定 `i`，所有满足 `j+k < n_i` 的单项式 `x^i y^j z^k` 都标准：因为 `x^i y^(j+k)` 标准，而把部分 `y` 换成 `z` 使同次单项式 lex 变小。由 (3)，这些单项式的总次数至多 `n_0-1`。

每列的这组三角形单项式有 `n_i(n_i+1)/2` 个。不同 `i` 的集合不交。因此把 (1) 用于 `D=n_0-1`，得到关键不等式

\[
\boxed{\sum_{i=0}^{\alpha-1}\frac{n_i(n_i+1)}2
\le1+(n_0-1)w.}
\tag{4}
\]

这也可以由现有逐次数计数 `H_d >= q_d(h_d)` 换序求和得到；上面的显式三角形集合注入避免了换序时的边界问题。

## 3. 前缀预算给出 alpha <= w-2

低次数完全标准，所以现有前缀计数及预算给出

\[
\binom{\alpha+2}{3}\le1+(\alpha-1)w.
\]

利用恒等式

\[
\alpha(\alpha+1)(\alpha+2)-6
=(\alpha-1)(\alpha^2+4\alpha+6)
\]

及 `alpha >= 2`，约去正数 `alpha-1` 可得

\[
\alpha^2+4\alpha+6\le6w.
\tag{5}
\]

若 `alpha >= w-1`，则 (5) 蕴含

\[
6w\ge(w-1)^2+4(w-1)+6=w^2+2w+3,
\]

即 `(w-1)(w-3) <= 0`，与 `w >= 4` 矛盾。由于参数是整数，

\[
\boxed{\alpha\le w-2.}
\tag{6}
\]

这一步解释了宽度 3 的障碍：该参数约束在 `w=3, alpha=2` 时不成立，证明不会错误地覆盖已有宽度 3 反例。

## 4. 完成平方与 Cauchy 不等式

在实数或整数中定义长度为 `alpha` 的向量

\[
v_0=2n_0+1-2w,\qquad v_i=2n_i+1\quad(1\le i<\alpha).
\]

由 (2)，

\[
\sum_i v_i=2\ell+\alpha-2w=:S.
\tag{7}
\]

由 (4) 直接展开得

\[
\begin{aligned}
\sum_i v_i^2
&=4\sum_i n_i(n_i+1)+\alpha-8wn_0-4w+4w^2\\
&\le 4(w-1)(w-2)+\alpha.
\end{aligned}
\tag{8}
\]

Cauchy 不等式于是给出

\[
\boxed{S^2\le\alpha\,[4(w-1)(w-2)+\alpha].}
\tag{9}
\]

这里 **`v_0` 可以为负**，证明不要求向量逐项非负。若希望避免调用实数 Cauchy，可用纯整数恒等式

\[
\alpha\sum_i v_i^2-(\sum_i v_i)^2
=\sum_{i<j}(v_i-v_j)^2\ge0.
\]

(9) 本身也给出一个保留 `alpha` 的闭式上界：

\[
\ell\le w-\frac\alpha2+
\sqrt{\alpha(w-1)(w-2)+\frac{\alpha^2}4}.
\tag{10}
\]

结合 (5)，其渐近阶为 `O(w^(5/4))`；最终二项式目标只需要更粗的 (6)。

## 5. 与二项式目标的纯代数比较

令

\[
T=w^2-w-\alpha-2.
\]

由 (6)，`T >= w(w-2) > 0`。另一方面，精确因式分解为

\[
\begin{aligned}
T^2-\alpha[4(w-1)(w-2)+\alpha]
&=(w-2)\big[(w-2)(w+1)^2-2\alpha(3w-1)\big]\\
&\ge (w-2)^2\big[(w+1)^2-2(3w-1)\big]\\
&=(w-2)^2(w-1)(w-3)>0.
\end{aligned}
\tag{11}
\]

(9) 与 (11) 给出 `S^2 < T^2`。因为 `T > 0`，必有 `S < T`，即

\[
2\ell+\alpha-2w<w^2-w-\alpha-2,
\]

所以

\[
\alpha+1+\ell<\frac{w(w+1)}2=\binom{w+1}{2}.
\]

两端都是整数，于是得到开头框内的强化界。**没有枚举 alpha 或 w，也没有依赖根式的数值近似。**

## 6. 另外两个目标与代数应用边界

记 `C=binom(w+1,2)`。由上述结论，`ell <= C-alpha-2`，因而

\[
\alpha+2\ell\le2C-\alpha-4\le2C
\le2\binom{w+1}{3},
\]

最后一步使用 `w >= 4` 及 `binom(w+1,3)=C(w-1)/3 >= C`。同理

\[
\ell\le C\le3\binom{w+1}{4},
\]

因为 `3 binom(w+1,4)/C=(w-1)(w-2)/4 >= 1`。

因此现有组合结论的三个界均可统一扩展为 `w >= 4`。回到有限余长 lex 理想时，如果沿用已核对的 `b_0(L)=alpha+1+ell` 等公式，则第一个界还得到严格改进。半群归约仍需原论文的 Artinian、初始理想及 lex 比较；本报告仅消除大宽度界和有限枚举在**组合末段**的必要性，没有替代这些代数桥梁。

## 8. 探索过但未采用的路线

1. **直接求和原包络。** 累计约束可产生约为 `2w/d` 的尾部高度上界，求和会引入调和和或对数。预期可处理足够大的宽度，但需要额外阈值和小参数补丁；本轮没有完成这一条路线，也没有追加无界枚举。
2. **只用统一支持上界。** 由 `n_i <= 2w-2` 粗估 `ell <= alpha(2w-2)`，在 `w=40` 等边界附近不够有效。
3. **先消掉终端位置再用 Cauchy。** 把 (4) 的右边先估为 `1+(2w-3)w`，会得到 `ell^2+alpha ell <= alpha(4w^2-6w+2)`，但它在 `w=4,alpha=2` 等小参数处不够强。成功路线保留右端中的真实 `n_0`，随后完成平方；这个相关性正是关键。
