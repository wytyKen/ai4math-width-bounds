## 覆盖与方法

审计快照时间为 2026-10-06 19:14:53 UTC。`main` 为 `5165182b944382797ec1bc7c3b7cf13da993ab93`，本地 `origin/main` 为 `01450016b1c7fc7e669a1155f8d717f9a00fa5e0`。没有联网刷新远端，不能据此声称远端当前状态与本地跟踪引用完全同步。

- `git rev-list --all` 的 3 个可达提交全部纳入，覆盖 `main` 的 3 个提交及 `origin/main` 的 2 个提交；读取每个提交的 author、committer 和完整提交消息。
- 对各提交执行递归 tree 清单，并补查 2 个内部树引用所指的同一树；后者未增加独有文件或 blob。合计 275 个历史 tree 路径、283 个去重 blob。
- 279 个 blob 是可解码的 UTF-8 文本，共 4,388,709 字节；其余 4 个为发布 PDF，由 R111 检查 PDF 内容和元数据。本扫描另对二进制做了有限的明文密钥/已知令牌标记检查，不替代 R111。
- 对全部文本逐行检查常见私钥标记、GitHub/OpenAI/AWS/Google/Slack 令牌形态、JWT、Authorization/Bearer/Basic 值、敏感字段赋值、带凭据 URL、敏感查询参数、邮箱和带电话标签的号码。另搜索敏感关键词并复核所有候选语境。
- 对全部历史 tree 路径检查 `.env`、常见凭据配置、SSH/云服务目录、密钥/证书容器、数据库与备份类型、个人应用目录；对 `results/` 和日志扩展类型作单独归类。普通数字、数学常数和摘要不作为电话号码判定。
- Git 现有姓名和邮箱只用于本地精确比较；本报告不复述其值。没有修改 Git 配置、索引、历史或远端，没有执行构建或编译。

## 集成建议与限制

根智能体可按 R109 补强忽略规则，预防今后加入凭据、机器配置和密钥；不需要为此次“未发现实际秘密”的结果重写历史。`.gitignore` 不会从已跟踪文件或旧提交中删除内容，因此本次历史扫描独立于规则是否覆盖。冻结原件、科学日志及 claims 的既有字节证据应保持原样。

本次检查的是审计时本地所有引用可达的提交/tree；不检查不可达 Git 对象、GitHub 服务端保留副本、外部备份、被忽略的本地私人目录，亦不声称识别了所有未知格式或经过加密/编码的秘密。工作区本轮新增报告及根智能体的最终提交载荷由 R109 做集成复核。

完整逐 blob 清单、精确匹配和现有身份值只保存在被忽略的 `tmp/r110_private/audit_private.json`；执行脚本及安全统计也只在该临时目录。它们不属于公开交付，不应暂存。公开报告不包含私密匹配值。

启动时 `checkpoint.py --check` 通过；`--verify-latest` 的归档有效，工作区仅有已登记任务导致的 queue 后续修改，与归档损坏不同。本子任务仅新增本报告和独占临时审计文件；状态、claims、检查点和最终提交由根智能体集成。审计完成后停止，不延伸研究任务。
