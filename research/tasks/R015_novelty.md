# R015：全宽度严格界与列长方法的定向查新

日期：2026-09-23。状态：完成有限范围查新；**新颖性未定**。六轮网络调用已用尽（检索与必要原文打开合并计数），未外联、未修改其他文件。正文约1500中文字以内。

**结论。** 本轮未找到覆盖任意四生成元、全部宽度的既有定理，也未找到在相同逐次数预算下给出严格界 `mu(L)≤binom(w+1,2)−1` 或相同 `O(w^(5/4))` 列长估计的文献。已有技术覆盖 lex 归约、截面计数与固定余长极值；不能将这些部件或 Cauchy 本身列为原创。本结论是有限检索结果，不是“此前无人证明”的认证。

1. **直接覆盖范围。** CMS 的 [2307.05770v2](https://arxiv.org/html/2307.05770v2) 定理5.1明确假设 `w≥40`，结论为非严格二项式界；备注5.2明确留下 `4≤w≤39`。其式(12)已经参数化二维阶梯，备注指出需利用完整阶梯序列及全部 Hilbert–Samuel 约束。因此“采用列长”不是独立新贡献；本项目可主张的候选增量是终端统一三角预算、保留 `n0` 完成平方及所得全范围严格结论。有限余长条件、半群归约及 `w=3` 单独处理仍须保留。

2. **近期结果未构成一般覆盖。** [Sally 型论文v3](https://arxiv.org/html/2507.11738v3)（2026-01-27）推论4.8仅对 `S^e(m,n)` 证明第一 Betti 的 width bound，不是任意四生成元。2025年[最小表示论文v1](https://arxiv.org/html/2405.19810v1)研究固定生成元数与重数，涉及 width 时仍指回 CMS。作者[研究目录](https://sites.google.com/site/alessiosammartano/research)未列出一般补齐论文。另检到2026年9月的[2609.24880](https://arxiv.org/abs/2609.24880)，摘要限定 almost symmetric 且 almost complete intersection；本轮只核摘要，不能将它当作一般解答或完成逐定理排除。

3. **较早相似不等式。** 最小表示论文定理2.2复述 Valla 的固定总余长 Betti 极值定理；命题2.5比较截面余长，紧随其后的讨论研究不取等情形。Caviglia–Sammartano [1903.08770v3](https://arxiv.org/pdf/1903.08770v3)（2023-01-06）定理3.7在固定长度与给定 Clements–Lindström 环内比较全部总 Betti 数，证明按变量分层。这些是明确的技术先例，却未给当前逐次数线性预算下的列平方和。Valla [1994原稿](https://www.numdam.org/article/CM_1994__91_3_305_0.pdf)已定位；本轮该定理具体口径以2025原论文定理2.2核对，未重审1994证明。

4. **为何不能直接套用旧极值定理。** 固定 `w` 的预算不控制三维总余长：`L=(x²,xy,xz,y²,yz,z^N)`、`N≥3` 是有限余长 lex 理想，满足 `HS(d)≤1+3d`，余长却为 `N+2`。这是本报告的直接数学核算，说明固定余长极值定理不能单独替代当前截面预算。尚未排除它与其他细化结果组合后导出相近估计。

5. **方法口径与后续。** 精确候选增量为 `Σ binom(n_i+1,2)≤1+(n0−1)w`，进而 `(2ell+alpha−2w)²≤alpha[4(w−1)(w−2)+alpha]`；结合 `alpha=O(sqrt(w))` 得 `ell=O(w^(5/4))`。本轮用“lexsegment/Hilbert–Samuel/colength/sum of squares/Cauchy/width/5/4”等交叉检索，未定位相同结果；关键词无命中证据很弱。建议在新稿中称“本文证明的强化估计，已知文献中未定位”，引用 CMS 为主归约来源，继续形式化，不以等待外部审稿为前提。
